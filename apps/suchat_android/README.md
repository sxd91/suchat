# Suchat Android

Kotlin + Jetpack Compose Android flagship client.

## Product defaults

- Appearance mode defaults to `LiquidGlass`.
- Performance profile defaults to `Full`.
- Both choices belong to **我的 → 外观** and are always user-selected, never device-detected.
- Shared-element navigation is the primary page transition. Miuix and AOSP are selectable alternatives.
- Material Symbols follows the icon family used by WeKit.
